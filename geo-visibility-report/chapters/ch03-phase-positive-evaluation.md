# Chapter 3: 正面评估期

## Core Idea
正面评估期是用户决策路径的**第一站**——用户已经知道品牌存在，主动询问"XX 品牌怎么样""XX 品牌好不好"。这阶段的目标是**确保品牌被正向推荐**、**抢占 AI 答案的前排位置**、**建立品牌的第一印象资产**。

## Frameworks Introduced

### 正面评估期用户意图特征

**典型提问**：
- "联想笔记本怎么样"
- "联想 ThinkPad 好不好用"
- "联想 vs 华为哪个好"
- "联想笔记本值得买吗"

**用户心理**：
- 已建立基础认知，处于"确认 / 比较"阶段
- 期待正面信息佐证自己的兴趣
- 决策尚未发生，最易被内容影响

**AI 答案的责任**：
- 给出明确推荐或比较结论
- 提供具体卖点、场景匹配、用户口碑
- 引用权威平台（媒体、官网、评测）

### 正面评估期的 4 个诊断模块

| 模块 | 关键指标 | 优化方向 |
|------|----------|----------|
| **基础数据** | 问题数、对话数、可见度、引用源量 | 检测覆盖完整性 |
| **统计说明** | 计算口径、数据清洗规则 | 数据可信度 |
| **优化分析** | 引用源质量、引用率、相关性 | 内容储备诊断 |
| **竞品分析** | 竞品可见度、竞品排序 | 差距识别 |

### 引用源质量分析（核心模块）

**关键判断逻辑**：
```
引用源占比低 → 内容储备不足 → 加大品牌内容生产
引用源占比高 + 可见度低 → 内容质量/平台权重/可信证据不足
引用源占比高 + 可见度高 → 健康状态，持续优化
```

**联想-豆包案例**：
- 相关文章总量：166 篇
- 引用源总量：312 个
- 引用率：53.2%
- 品牌正面可见度：100%
- 平均排名：1.2
- 解读：引用率健康，模型高度接触品牌 → 优秀状态

### 竞品可见度对比（差异化机会）

**联想案例数据**（部分）：
- 联想：千问/文心/豆包/元宝 = 100%，DeepSeek 90%，Kimi 80%
- 华硕：千问/文心/豆包 = 100%，元宝 90%，DeepSeek/Kimi 80%
- 惠普：千问 60%，豆包/Kimi 90%，文心 100%
- 戴尔：千问 60%，文心 90%，豆包 90%，Kimi 90%

**解读模板**：
1. 联想在 4 个模型满分，DeepSeek/Kimi 有短板
2. 短板对应"年轻高知用户"群体，警惕被惠普/戴尔反超
3. 竞品已全面拥抱 GEO 优化，不进则退

## Key Concepts

- **正面评估期 = 品牌的"门面"**：第一眼印象决定后续决策路径
- **可见度 100% ≠ 优化到位**：还要看排名、情感、引用源质量
- **短板模型 = 高 ROI 优化点**：从 90% 到 100% 的边际成本远低于从 30% 到 60%
- **跨模型差异 = 用户群体差异**：豆包用户与 Kimi 用户画像不同，需差异化内容

## Mental Models

- **"先打穿一个模型，再扩散"**：正面评估期应优先打满主导模型，建立标杆案例
- **"排名 > 可见度"**：同样被提及，排名 1 vs 排名 5 的转化率可能差 5 倍
- **"竞品对标不是嫉妒，是找差距"**：通过竞品可见度矩阵识别自己模型的盲区

## Anti-patterns

- **❌ 只追求全模型 100% 可见度**：忽略排名、情感等更深层指标
- **❌ 用 SEO 思维做正面评估期**：关键词堆砌在 GEO 时代已被 AI 识别为低质
- **❌ 引用源只看数量不看质量**：100 篇低质内容 < 10 篇权威内容
- **❌ 不做竞品对比**：看不到差距就没有优化方向

## Key Takeaways

1. 正面评估期是用户决策第一站，决定品牌第一印象
2. 4 个诊断模块：基础数据 + 统计说明 + 优化分析 + 竞品分析
3. 引用源质量分析三态：低占比 = 内容储备不足；高占比低可见度 = 质量/平台问题；高占比高可见度 = 健康
4. 短板模型识别是 ROI 最高的优化点
5. 竞品对标不是嫉妒，是识别自己模型的盲区
