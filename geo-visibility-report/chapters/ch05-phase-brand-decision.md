# Chapter 5: 品牌决策期

## Core Idea
品牌决策期是用户决策路径的**最后一站**——用户已经完成正面评估和负面质疑，准备下单。这阶段的关键不是"有没有答案"，而是"答案是否有效、是否正向、是否足以支撑用户做选择"。如果某模型有效率或正面率偏低，品牌在最后一步可能被竞品截走。

## Frameworks Introduced

### 品牌决策期用户意图特征

**典型提问**：
- "联想笔记本和华为笔记本哪个好"
- "联想 ThinkPad 和 YOGA 哪个好"
- "联想笔记本售后服务好吗"
- "联想笔记本值得买吗"
- "推荐一款联想笔记本"

**用户心理**：
- 已经做了初步筛选，准备做最终决策
- 需要的是"对比 + 结论 + 理由"
- 期待明确推荐，而非客观陈述

**AI 答案的责任**：
- 给出明确的对比结论
- 推荐理由要具体、可验证
- 售后、保障、价格等决策信息要完整

### 品牌决策期的 4 个诊断模块

| 模块 | 关键指标 | 优化方向 |
|------|----------|----------|
| **基础数据** | 决策问题数、决策可见度、决策引用源量 | 决策覆盖广度 |
| **统计说明** | 有效回答率、正面率定义 | 数据有效性 |
| **优化分析** | 决策引用源追踪、有效回答占比 | 决策基础健康度 |
| **竞品分析** | 竞品决策表现、对比 | 决策截流风险 |

### 联想案例：品牌决策期问题诊断

| 提问词 | 模型 | AI 情感 | 优先级 |
|--------|------|---------|--------|
| 联想笔记本和华为笔记本哪个好 | 文心 | 无说明（无效） | 高 |
| 联想 ThinkPad 和 YOGA 哪个好 | 豆包 | 中性 | 中 |
| 联想笔记本售后服务好吗 | 千问 | 中性 | 中 |
| 联想笔记本和华为笔记本哪个好 | 元宝 | 中性 | 中 |
| 联想笔记本售后服务好吗 | DeepSeek | 中性 | 中 |
| 联想 ThinkPad 和 YOGA 哪个好 | Kimi | 中性 | 中 |

**解读**：
- 决策期全部问题未达"有效 + 正面"标准
- 文心出现"无效"回答——必须立即修复
- 5 个模型全是"中性"——品牌未建立决策期的偏好

### 品牌决策期"4 步打造"策略

#### 第 1 步：补齐决策资料缺口
- 基于企业核心优势分析用户真实场景问题
- 构建针对性内容体系
- 发布结构化、可对比的内容

#### 第 2 步：提升正向表达密度
- 让大模型不只是"能回答"
- 能更明确地给出偏正向的判断与推荐理由
- 决策期不能客观中立——必须有立场

#### 第 3 步：追踪并干预不利引用源
- 凡是引发负面或削弱品牌倾向的引用平台和相关文章
- 都需要尽快排查、处理和替换
- 决策期的引用源质量比数量更重要

#### 第 4 步：布局高频共用引用平台
- 这些都是影响大模型决策判断的重要入口
- 不主动进入，就会持续被竞品占位
- 一篇决策期内容应该跨 3+ 模型

### 品牌决策期的"基础信息完整度"诊断

**决策基础 7 项必备**：
1. 产品对比表（vs 竞品）
2. 价格与性价比分析
3. 售后服务承诺
4. 适用人群与场景
5. 优缺点诚实陈述
6. 真实用户评价
7. 购买渠道与保障

**诊断逻辑**：
```
基础信息完整 → 只能保证品牌不掉队
持续补齐底层内容 → 才能争夺优先推荐位置
```

## Key Concepts

- **品牌决策期 = 临门一脚**：前期铺垫再好，最后一步拉胯就白做
- **决策期不能客观中立**：用户要的是推荐，不是百科
- **基础信息完整 = 及格线**：必须先达到，再谈偏好
- **决策期有效率 ≥85% 才算合格**：低于此说明 AI 答案不足以支撑决策
- **决策期正面率 ≥60% 才算健康**：低于此说明品牌在 AI 心中未建立优势

## Mental Models

- **"决策期内容是销售话术的 AI 化"**：把 B2B 销售的"竞品对比 + 优势强调 + 售后保障"转化为 AI 可引用的结构化内容
- **"无效回答 = 决策失败"**：模型说"无法比较 / 各自有特点"对品牌来说等于零
- **"基础信息 = 及格线"**：决策期内容先求全，再求好"

## Anti-patterns

- **❌ 决策期内容只描述自家产品**：用户要的是对比，不是单品介绍
- **❌ 客观中立不站队**：用户期待推荐，客观中立会被解读为"品牌没信心"
- **❌ 没有售后 / 价格 / 场景信息**：决策期最关键的信息缺失
- **❌ 不监测"无效回答"**：无效是比负面更严重的失败——负面至少能修，无效说明 AI 完全没掌握品牌信息

## Key Takeaways

1. 品牌决策期是临门一脚，决定最终转化
2. 4 步打造策略：补齐决策资料 + 提升正向表达 + 追踪不利引用 + 布局高频共用
3. 决策期 7 项必备基础信息
4. 决策期不能客观中立——必须有立场
5. 决策期有效率 ≥85%、正面率 ≥60% 是健康基线
