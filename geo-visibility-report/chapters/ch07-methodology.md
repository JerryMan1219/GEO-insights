# Chapter 7: GEO 优化执行方法论

## Core Idea
GEO 优化不是"全面铺开、平均发力"，而是**"先聚焦，再扩张"**——优先打穿优势场景，再向更大流量场景扩展。本章节整合正面评估期、负面质疑期、品牌决策期的优化方法论，给出可执行的 GEO 优化框架。

## Frameworks Introduced

### 核心方法论：先聚焦，再扩张

**错误做法**：
- 平均分散到所有场景，每个场景都不深
- 最终没有一个问题真正属于自己
- 见效慢，无法形成大模型对品牌的共识标签

**正确做法**：
- 前期优先围绕自身最具优势、最易形成正向推荐的核心场景深耕
- 先打穿一个高匹配场景，优先被推荐、排名靠前
- 再逐步向需求和更大流量场景扩展

### 正面评估期优化方法论

**3 个核心动作**：

1. **汇总需优化的提问词**
   - 找出"竞品被推荐但品牌未出现"的提问词
   - 找出"品牌被提及但排名靠后"的提问词
   - 围绕这些问题发布高质量、权威性内容

2. **筛选大模型共用引用平台**
   - 识别跨模型共用的引用源平台
   - 优先在这些平台发布内容
   - 一篇帖子多平台引用，事半功倍

3. **GEO 后续优化执行方法论（应用先聚焦原则）**
   - 先打穿 1 个高匹配场景
   - 再向更大流量场景扩展
   - 形成大模型对品牌的"共识标签"

### 负面质疑期优化方法论

**4 步重建策略**（已在 ch04 详解，此处整合）：

| 步骤 | 核心动作 | 输出物 |
|------|----------|--------|
| **事实核查** | 判断负面类型 | 负面清单 + 分类 |
| **问题澄清** | 补充官方说明 | FAQ、对比说明 |
| **内容修复** | 发布平衡内容 | 正向内容矩阵 |
| **平台重建** | 布局高频引用平台 | 新引用源体系 |

**关键原则**：
- 商业向善 / 科技向善：不造假、不投毒、不操控
- 基于真实业务、真实产品、真实用户需求
- 构建 AI 易理解、易引用、易推荐的内容体系

### 品牌决策期优化方法论

**4 步打造策略**（已在 ch05 详解，此处整合）：

1. **补齐决策资料缺口**
   - 基于企业核心优势分析用户真实场景问题
   - 构建针对性内容体系
   - 发布结构化内容

2. **提升正向表达密度**
   - 让大模型不只是"能回答"
   - 能更明确地给出偏正向的判断与推荐理由

3. **追踪并干预不利引用源**
   - 引发负面或削弱品牌倾向的引用平台和相关文章
   - 尽快排查、处理、替换

4. **布局高频共用引用平台**
   - 影响大模型决策判断的重要入口
   - 不主动进入，就会持续被竞品占位

### GEO 优化优先级矩阵

| 优先级 | 信号 | 行动 |
|--------|------|------|
| 🔴 高 | 竞品被推荐但品牌未出现 | 立即补充品牌内容 |
| 🔴 高 | 品牌负面情感 | 立即事实核查 + 澄清 |
| 🔴 高 | 品牌排名 5+ | 优化内容质量与平台权重 |
| 🟡 中 | 品牌被提及但排名 3-5 | 提升内容权威性 |
| 🟡 中 | 引用源质量低 | 替换为权威平台 |
| 🟢 低 | 品牌表现合格 | 持续监测 + 维护 |

### 内容生产原则

**4 特征内容矩阵**：
- **专业/权威性**：建立 AI 信任
- **一致性**：跨平台信息口径对齐
- **时效性**：保持内容前沿
- **语义增强**：强化意图匹配

**3 层信源分发**：
- **权威层**：官网、百科、论文（打底）
- **讨论层**：社媒、UGC、社区（引爆）
- **平台层**：电商、内容平台（补漏）

### 自建 vs 外包决策

| 维度 | 自建模式 | 外包（专业服务商） |
|------|----------|---------------------|
| 综合成本 | 高（薪资、招聘、工具） | 服务费清晰 |
| 核心能力 | 从零摸索，效果无保障 | 成熟方法，效果承诺 |
| 启动速度 | 3-6 个月 | 1 个月内见效 |
| 内容运营 | 易沿用 SEO 思维偏差 | 体系化生产，更符合 AI 偏好 |
| 管理投入 | 大量精力协调 | 轻量对接 |

**判断标准**：
- 资源充足 + GEO 是核心战略 + 长期投入 → 自建
- 资源有限 + 快速验证 + 中短期项目 → 外包

## Key Concepts

- **先聚焦，再扩张**：GEO 不是平均发力，而是单点突破
- **负面修复 = 长期工程**：不是一次性项目
- **决策期不能客观中立**：必须有立场
- **商业向善 = 底线**：不刷量、不复制、不投毒
- **自建 vs 外包 = 资源 vs 速度的权衡**

## Mental Models

- **"打穿一个场景 > 平均铺开"**：1 个 90% 可见度场景胜过 10 个 30% 场景
- **"负面修复是马拉松不是短跑"**：需要持续监测与迭代
- **"决策期 = 销售话术 AI 化"**：把人类销售的对比、推荐、理由转化为 AI 可引用的结构化内容
- **"外包不是认输，是借力"**：GEO 是技术 + 经验密集型，外包可能比自己摸索快 3-6 个月"

## Anti-patterns

- **❌ 全面铺开**：资源分散，没有一个场景打透
- **❌ 一次性优化**：GEO 是持续运营，不是项目上线即结束
- **❌ 沿用 SEO 思维**：GEO 是语义信任，SEO 是关键词排名
- **❌ 不做效果监测**：不知道哪些优化生效、哪些失效
- **❌ 追求短期效果**：刷量、投毒等黑帽手段短期有效，长期必死

## Key Takeaways

1. 核心方法论：先聚焦，再扩张
2. 负面质疑期 4 步重建：事实核查 → 问题澄清 → 内容修复 → 平台重建
3. 品牌决策期 4 步打造：补齐资料 → 提升正向 → 追踪不利 → 布局共用
4. 优先级矩阵：高（竞品出现/负面/排名差）→ 中（排名中/质量低）→ 低（合格）
5. 内容 4 特征 + 信源 3 层
6. 自建 vs 外包根据资源与战略权衡
