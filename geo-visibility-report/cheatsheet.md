## 优先级矩阵速查

| 优先级 | 信号 | 立即行动 |
|--------|------|----------|
| 🔴 高 | 竞品出现但品牌未出现 | 立即补充品牌内容 |
| 🔴 高 | 品牌负面情感 | 立即事实核查 + 澄清 |

| 🟢 低 | 品牌表现合格 | 持续监测 + 维护 |

## 品牌决策期 7 项必备基础信息

| # | 必备信息 | 缺失后果 |
|---|----------|----------|
| 1 | 产品对比表 | AI 无法给出对比结论 |
| 2 | 价格与性价比 | AI 不敢推荐（怕误导） |
| 3 | 售后服务承诺 | 用户最后一步流失 |
| 4 | 适用人群与场景 | 答案过于宽泛 |
| 5 | 优缺点诚实陈述 | 失去信任 |
| 6 | 真实用户评价 | 答案空洞 |
| 7 | 购买渠道与保障 | 决策闭环失败 |

## 紧急问题决策树

```
品牌在 AI 答案中找不到？
├─ 是 → 引用源占比低 → 加大品牌内容生产
└─ 否 → 但可见度低 → 优化内容质量与平台权重

品牌负面情感？
├─ 是 → 4 步重建（事实核查→问题澄清→内容修复→平台重建）
└─ 否 → 维持现状 + 持续监测

品牌决策期无效？
├─ 是 → 7 项必备信息缺失 → 立即补齐
└─ 否 → 持续优化决策基础 + 提升正向密度

跨模型表现差异大？
├─ 是 → 短板模型识别 → 定向优化（重点打穿 1-2 个）
└─ 否 → 全面铺开 → 平均深度不足 → 转向"先聚焦再扩张"

竞品在某模型领先？
├─ 是 → 分析竞品内容策略 → 对标优化
└─ 否 → 保持优势 + 持续监测
```
