# Chapter 7: B2C vs B2B GEO 策略对比（消费决策 AI 搜索洞察报告）

## Core Idea
B2C 与 B2B 的 AI 搜索决策路径、决策者、信任构建逻辑差异巨大，GEO 策略必须按业务模式差异化设计；不同消费品类的 AI 搜索渗透率从 44%（美妆）到 67%（旅游）不等，B2B 高达 91%。

## Frameworks Introduced
- **B2C vs B2B GEO 5 维对比**：

| 维度 | B2C | B2B |
|------|-----|-----|
| 核心目标 | 提升转化率/GMV | 提升询盘与留资质量 |
| 决策者 | 个人决策或家庭成员 | 多部门/多职级专业人士 |
| 决策路径 | 短，场景驱动 | 长周期、高度理性、多部门 |
| 信任构建 | 品牌口碑、用户反馈、社媒 | 权威背书（论文/专利/认证/案例） |
| 效果衡量 | 点击率、转化率、GMV、订单量 | 询盘量、留资率、线索质量、销售周期 |

  - When to use: 决策品牌 GEO 资源分配
  - How: 按业务模式定位，差异化设计内容矩阵

- **9 大消费品类 AI 搜索渗透率表**（N=1000）：

| 品类 | 渗透率 | 核心信息关注 |
|------|--------|--------------|
| 旅游出行 | 66.9% | 产品详情 72.7% / 品牌口碑 70.6% |
| 手机 | 58.8% | 价格采购 71.1% / 品牌口碑 71.1% |
| 医疗保健 | 57.0% | 品牌口碑 73.2% / 产品详情 75.4% |
| 本地到店 | 55.6% | 场景适配 70.3% / 品牌口碑 69.3% |
| 知识教育 | 51.3% | 场景适配 79.3% / 价格采购 71.9% |
| 专业服务 | 51.2% | 品牌口碑 78.8% / 场景适配 78.0% |
| 汽车 | 46.6% | 品牌口碑 71.1% / 产品详情 68.4% |
| 美妆个护 | 44.3% | 产品详情 74.7% / 品牌口碑 73.7% |
| **B2B（企业用户）** | **91.3%** | 参数成本对比 64.4% / 行业方案 61.8% / 匹配供应商 56.0% |

  - When to use: 评估品牌所在品类的 AI 搜索渗透率优先级
  - How: 高渗透率品类优先布局 GEO

- **B2C 三大品类子策略**：
  - **高决策复杂度（汽车/家电）**：结构化知识库 + 全链路内容布局 + 全域信息口径对齐 + 分层转化
  - **快消品（美妆/个护）**：内容生命周期管理 + 多形态内容 + 知识科普与舆情管理 + 嵌入转化入口
  - **实体服务（到店/教育/专业服务）**：本地长尾精准卡位 + 跨平台信息对齐 + 分层转化路径
  - When to use: 设计 B2C 品类 GEO 方案
  - How: 按品类决策复杂度匹配策略

- **B2B 按岗位差异化**：
  - 信息/IT 部门 TGI=124
  - 中高层 TGI=131
  - GEO 决策链优化需覆盖采购+技术+管理层多角色
  - When to use: 设计 B2B GEO 内容矩阵
  - How: 按岗位角色设计意图词库与内容

- **B2B 内容矩阵三模块**：
  - **基础必备案**：资质/案例/服务范畴
  - **核心流量**：横向对比/场景问答
  - **轻量补充**：趋势解读/科普
  - When to use: 构建 B2B 内容资产
  - How: 基础备案覆盖长尾需求、核心流量抓住决策路径、轻量补充塑造专家形象

## Key Concepts
- **AI 搜索渗透率**：某品类消费决策前使用 AI 搜索的用户比例
- **TGI（Target Group Index）**：目标群体指数，>100 表示该群体高于平均
- **品牌口碑（AI 时代的解读）**：用户反馈 + 评测 + 社媒讨论的综合表现
- **分层转化**：按决策阶段（认知→考虑→比较→决策）设计不同的转化路径
- **B2B 决策链**：从信息搜集→方案对比→供应商筛选→商务谈判→采购决策的长链路

## Mental Models
- **"信息关注 Top 3" 是 GEO 内容设计的核心**：产品详情 + 品牌口碑 + 场景适配几乎覆盖所有品类
- **"高决策复杂度 = 高结构化需求"**：汽车/家电/医疗需要的是知识库，不是软文
- **"B2B = 长决策链 GEO"**：一个决策涉及多个岗位，内容要覆盖所有角色

## Anti-patterns
- **用 B2C 软文打法做 B2B**：B2B 决策者是专业人士，需要权威背书和数据支撑
- **不区分品类设计 GEO 策略**：快消品和高决策复杂度品类策略应该不同
- **忽视本地长尾**：到店类服务依赖本地化 GEO，长尾搜索词卡位是关键

## Key Takeaways
1. B2C vs B2B 在 5 个维度上差异巨大：目标/决策者/路径/信任/衡量
2. 9 大消费品类 AI 搜索渗透率从 44%（美妆）到 67%（旅游）不等
3. B2B 用户 AI 搜索渗透率高达 91.3%，远超 B2C
4. 信息关注 Top 3：产品详情 + 品牌口碑 + 场景适配（适用于几乎所有品类）
5. B2C 按决策复杂度分三种子策略：B2B 按岗位角色设计意图词库
6. B2B 内容矩阵三模块：基础备案 + 核心流量 + 轻量补充
