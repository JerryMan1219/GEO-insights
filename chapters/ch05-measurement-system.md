# Chapter 5: GEO 效果评估体系

## Core Idea
GEO 评估体系分四层（AI 可见性 / 内容层 / 技术层 / 业务层），但归因仍存技术瓶颈；行业普遍采用 "模拟真实用户与 AI 交互" 而非单纯调用 API。

## Frameworks Introduced
- **GEO 评估指标四层体系**：
  - **AI 可见性指标**——AI 首条占位/首推率、前 3 推荐率、置顶推荐率/心智占有率
  - **内容层指标**——AI 品牌情感倾向、AI 品牌卖点传递
  - **技术层指标**——AI 引用信源分布、内容引用率、内容存活周期、平台覆盖广度
  - **业务层指标**——AI 线索转化率、品牌官网访问率
  - When to use: 设计 GEO 项目的 KPI 体系
  - How: 四层指标分阶段推进——先 AI 可见性，再内容质量，再到技术效果，最终业务转化
- **两大评估方法对比**：
  1. **调用 AI 平台 API**：答案简洁，但 API 不同导致数据不一致，且无法反映真实搜索体验
  2. **模拟真实用户与 AI 交互**（**行业普遍选择**）：模拟真实用户提问方式，获取更丰富多维度的信息
  - When to use: 选择 GEO 监测工具
  - How: 优先采用第二种方法，并交叉验证
- **PureblueAI 清蓝 DRRR 归因模型**：
  - **D - Discover（发现）**：更好的用户意图匹配
  - **R - Recognize（认可）**：更可信的品牌内容
  - **R - Rank（排序）**：更高的采信权重
  - **R - Recommend（推荐）**：更多内容引用
  - When to use: 评估 GEO 优化全链路效果
  - How: 四步分别量化，形成 "发现-认可-排序-推荐" 的全链路追踪
- **优易科技 GEO 营销范式**（3 阶段）——对应业务转化：
  - 阶段 1：品牌可见度 + 声量提升至行业第一
  - 阶段 2：SPU 可见度 + 新品可见度提升
  - 阶段 3：新场景 + 新人群可见度与心智破圈
  - When to use: 规划品牌全阶段 GEO 战役
  - How: 按 "品牌→产品→新场景" 三阶段设计优化任务和衡量标准

## Key Concepts
- **优先推荐率**：指定意图平台搜索中，目标品牌/产品优先出现在推荐名单的比率
- **前三推荐率**：目标品牌/产品出现在推荐名单前三的比率
- **AI 引用信源分布**：AI 答案引用的源链接按域名/平台/类型的分布
- **心智占有率**：用户提及某品牌时，AI 是否将其放在核心位置
- **效果即服务**（Outcome-as-a-Service）：GEO 服务商按效果指标付费的商业模式
- **效果监测瓶颈**：实时监测成本高 + 归因难——类似效果广告 ROI 的具体转化指标缺失

## Mental Models
- **"先可见后转化" 的指标阶梯**：AI 可见性 → 内容质量 → 技术效果 → 业务转化
- **"效果即服务" 是 SaaS 模式延伸**：按推荐率/排名付费，降低品牌方风险
- **DRRR 是 GEO 全链路的 "漏斗模型"**：从发现到推荐逐级转化

## Anti-patterns
- **只看 AI 可见性指标**：忽视内容质量、技术层和业务转化
- **只调用 API 不模拟真实用户**：数据失真，误判效果
- **不重视品牌情感倾向**：被 AI 引用但情感为负，伤害品牌
- **不跨平台对比**：每个平台引用偏好不同，需分平台监测

## Key Takeaways
1. GEO 评估分四层：AI 可见性 + 内容层 + 技术层 + 业务层，需分阶段推进
2. 行业普遍选择 "模拟真实用户与 AI 交互" 而非单纯 API 调用
3. PureblueAI DRRR 归因模型是 GEO 全链路追踪的标准框架
4. 优易 GEO 三阶段范式：品牌可见→SPU/新品可见→新场景/新人群破圈
5. 效果即服务（Outcome-as-a-Service）正在成为 GEO 主流商业模式
6. 归因仍是行业技术瓶颈，需配合第三方数据补充
